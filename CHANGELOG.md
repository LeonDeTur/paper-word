# Changelog

Изменения группируются по SemVer. Даты — даты выпуска.

## [Unreleased]

### Added

- GitHub Actions: проверки качества, unit/integration на Linux и Windows, Chromium/Axe, coverage и Docker smoke test; отдельные CodeQL, аудит зависимостей и Dependabot.
- Release PR из `chore/release`: версии и русские разделы changelog из Conventional Commits, GitHub Release после успешного CI, runtime-архив и SHA-256 без личных данных.
- Локальные команды настройки и проверок, Git hooks, Commitlint, Oxlint, согласованные Node/редактор/окончания строк и руководство по разработке.
- MCP и HTTP API для поиска и чтения библиотеки, редактирования статей и переводов, фонового перевода, карточек, повторений и статистики. Сайт и MCP используют общий слой операций.
- Раздельные разрешения агентов, выбор прав при создании токена и OAuth; удаление требует дополнительного `data:delete` и по умолчанию выключено. Старые токены мигрируют с правом только импорта.
- OAuth с PKCE для Claude, сужение прав при refresh, одинаковые инструменты управления в удалённом MCP и stdio; сохранение переводов защищено от устаревших правок.
- Срок токена через календарь с датой и временем или команду в интерфейсе (`30d`, `12h`, `2w`, `31.12.2027 18:00`). Ограничение 365 дней снято; HTTP API поддерживает `expires_at` и `expires_in` с серверной проверкой срока.
- PolyForm Noncommercial License 1.0.0 для кода и документации; лицензия и уведомление об авторстве включены в Docker-образ.

## [0.2.0] - 2026-10-25

### Added

- Личная библиотека HTML, PDF и статей по ссылкам; исходные файлы и переводы сохраняются в SQLite.
- Читалка с переводами абзацев, словарными подсказками, закладками и прогрессом чтения.
- Карточки EN → RU и RU → EN с независимыми интервалами и защитой от дубликатов начальных форм.
- OpenAI-совместимый API моделей, включая Ollama; продолжение частичного перевода после ошибки.
- HTTP API и MCP с ограниченными отзываемыми токенами, квитанциями и защитой от повторного импорта.
- OAuth с PKCE, подтверждением владельца, ротацией refresh-токенов и загрузкой файлов ChatGPT через MCP.
- Docker Compose, Caddy, готовый адрес для VPS и автоматическое получение доверенного HTTPS-сертификата.
- SemVer, журнал изменений и проверяемый выпуск Git-тегов.

### Fixed

- Монохромная чёрная тема и перевод слова при наведении; клик открывает карточку.
- Импорт словарных подсказок и переводов из шаблонов Spatial-RAG и GeoNatureAgent.

### Security

- Вход владельца, CSRF-защита, ограничения размеров и частоты запросов.
- Проверка публичных адресов, закрепление DNS и повторная проверка перенаправлений при загрузке.
- Токены и коды OAuth хранятся в виде хешей; временные ссылки на файлы ChatGPT не сохраняются.
- Примеры конфигурации обезличены перед первой публичной публикацией; БД, ключи, логи и локальные настройки исключены из Git и Docker build context.
