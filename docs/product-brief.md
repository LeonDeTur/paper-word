# Сервис переводов статей и изучения слов

Статус: первая рабочая версия, локальная проверка. Дата: 25 октября 2026 года.

## Подтверждено пользователем

- Личный веб-сервис для компьютера и телефона.
- Загрузка и управление переводами статей.
- Ориентир — постоянная задача «Найти и перевести актуальную статью».
- Нужны и импорт готовых переводов, и автоматический перевод через ИИ.
- Карточки для изучения английских слов.
- Размещение на собственном VPS, доступ только владельцу.
- Приоритетный импорт: HTML из постоянной задачи, PDF и ссылки.
- Карточки EN → RU и RU → EN, независимые интервалы в обоих направлениях.
- Слово или выражение добавляется в начальной форме; дубликаты запрещены.
- Начальные интервалы: 10 минут / 12 часов / 1 день / 4 дня.
- Ollama подключается через OpenAI-совместимые эндпоинты; прямой зависимости от нативного API Ollama нет.
- Визуальное направление пользователь доверил выбрать исполнителю.

## Формат готовых статей

Импорт поддерживает автономный HTML с английским текстом, русским переводом абзацев, RU / RU ALL, BLACK / LIGHT и переводом слов по касанию. Реконструированные рисунки и ограничения исходного материала должны обозначаться явно.

Размещение на собственном VPS, открытие на мобильных устройствах и полнота переводов слов входят в требования. Офлайн-режим в объём первой версии не включён.

## Основной путь

Добавить статью → открыть английский оригинал и перевод → нажать слово или выделить выражение → сохранить карточку с контекстом → повторять слова.

## Что нужно для интеграции с реальными данными

- Проверка настоящих HTML завершена: Spatial-RAG и GeoNatureAgent Benchmark добавлены в локальную библиотеку, исходные файлы сохранены побайтово.
- Адрес OpenAI-совместимого API и имя установленной модели; ключ, если требуется, задаётся только на сервере.
- Домен и окружение VPS для проверки реального размещения.

## Реализация первой версии

React и TypeScript, Node.js 24 с Express, SQLite. Спокойный интерфейс чтения со светлой и чёрной темами. Код находится в `src` и `server`; инструкция и ограничения — в `README.md`. Добавлены библиотека, читалка, словарь, повторение, настройки модели, вход, сохранение исходников и JSON-экспорт. Дубликаты начальных форм блокируются уникальным ограничением БД. Две стороны карточки имеют отдельное расписание. Автоподсказку начальной формы можно исправить перед сохранением.

## Критерии приёмки и границы проверки

- AC-001. Добавленная статья появляется в библиотеке, сохраняется после перезапуска и открывается на другом устройстве при использовании одного серверного хранилища. Проверка: API и браузер.
- AC-002. Импорт готового материала сохраняет оригинал и доступные переводы; отсутствующие переводы явно обозначены. Проверка: фикстуры импорта и визуальный просмотр. Совместимость с прежним HTML подтверждается только после проверки его реального образца.
- AC-003. Читатель показывает русский перевод отдельного фрагмента и всех фрагментов; пользователь может продолжить чтение с сохранённого места. Проверка: браузер на компьютере и телефоне.
- AC-004. Автоматический перевод выполняется на сервере через OpenAI-совместимый API; ключ не передаётся браузеру. Ошибка провайдера не уничтожает имеющийся текст. Проверка: подставной API; реальный сервер моделей ещё не настроен.
- AC-005. Карточка содержит слово или выражение, редактируемый перевод и контекст. Ссылка на источник позволяет вернуться к статье. Проверка: сценарий в браузере и API.
- AC-006. После оценки ответа сохраняется результат повторения и рассчитывается следующий срок. Вариация SM-2 с согласованными начальными интервалами применяется независимо к двум направлениям. Проверка: детерминированные тесты и обе стороны карточки в браузере.
- AC-007. Импорт HTML не исполняет скрипты исходного файла в приложении; загрузка по ссылке не даёт доступ к внутренним адресам сервера. Проверка: тесты вредоносных HTML и URL.
- AC-008. Одинаковая начальная форма с другим регистром или пробелами не создаёт второй записи. Проверка: API возвращает 409, браузер блокирует кнопку сохранения после определения существующей формы.
- AC-009. Production требует пароль и HTTPS-источник. Выход и смена пароля отзывают сессии. Проверка: интеграционные тесты.

Локально пройдены 29 серверных тестов, включая HTTP API, OAuth ChatGPT/Claude, удалённый MCP официальным SDK-клиентом, управление библиотекой и повторениями, миграцию старых токенов и локальный stdio MCP с ограничением папки. Проверены сборка TypeScript/Vite и браузерные сценарии. Настоящие HTML импортированы: Spatial-RAG — 166 русских переводов фрагментов, GeoNatureAgent — 39; исходники сохранены без изменений. Фактические скриншоты и наблюдения находятся в `artifacts/qa`. Образ на Linux, доступ с физического телефона и реальный сервер моделей требуют проверки в целевом окружении.

## Применяемые навыки

- `ecc:intent-driven-development`: уточнение сценариев и проверяемых критериев готовности.
- `domain-modeling`: единые понятия статьи, перевода, фрагмента, карточки и контекста.
- `ecc:frontend-design-direction`: интерфейс чтения и занятий, адаптация к телефону и проверка состояний.
- `ecc:security-review`: обработка загруженных файлов, доступ к личным данным и хранение ключей.
- `ecc:react-patterns`: компоненты, локальное состояние, обработка ошибок и нативные формы.
- `ecc:mcp-server-patterns`: удалённый Streamable HTTP и локальный stdio MCP, общий набор инструментов импорта и управления библиотекой, переводами, карточками и повторениями.

## Уточнения следующего этапа

По запросу пользователя HTTP API и MCP расширены до поиска и чтения библиотеки, изменения переводов, управления карточками и повторениями. Права выбираются при создании токена и OAuth. Старые токены остаются только для импорта. Удаление требует отдельного `data:delete`, выключенного по умолчанию, и соответствующего права записи. Настройки сервера и секреты недоступны. Пользователь хочет проверить оба сценария: сайт и работу из ChatGPT/Claude. Интерактивные MCP Apps — отдельный следующий этап. Схема подключения — `docs/agent-integration.md`.

Тёмная тема сделана монохромной по настоящему файлу Spatial-RAG: фон #000000, белый текст и серые элементы. В светлой теме сохранён зелёный акцент.

Выбор стека сделан исполнителем в рамках задачи; первая версия предназначена одному пользователю на собственном VPS.
